# Trevor Schoeny's Claude Code Plugins

A personal marketplace for Claude Code plugins.

## Install

```
/plugin marketplace add trevorschoeny/claude-plugins
```

## Plugins

| Plugin | Description |
|--------|-------------|
| [cairn](https://github.com/trevorschoeny/cairn) | Architectural Knowledge Management — records the WHY behind your code so agents don't 'improve' away deliberate decisions. |
| [silcrow](https://github.com/trevorschoeny/silcrow-agency-helper) | Silcrow — Agency Helper. Scaffold a disciplined multi-agent agency with ADR decision tracking, async-auditor registrar, canonical/operational artifact discipline, and multi-unit support. |
| [operbe](https://github.com/trevorschoeny/operbe) | The operations and behaviors method. One list of operations every front end uses, and one list of behaviors every UI is built from and checked against. |
| [stop-safe](https://github.com/trevorschoeny/stop-safe) | A way of designing software in which nothing has to stay running. Four kinds of thing, eight statements, one test run four ways. |
