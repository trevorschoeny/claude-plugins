# Trevor Schoeny's Claude Code Plugins

A personal marketplace for Claude Code plugins.

## Install

```
/plugin marketplace add trevorschoeny/claude-plugins
```

## Plugins

| Plugin | Description |
|--------|-------------|
| [cairn](https://github.com/trevorschoeny/cairn) | Architectural Knowledge Management — records the WHY behind your code so agents don't 'improve' away deliberate decisions. |
